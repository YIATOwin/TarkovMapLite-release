# 电脑任务侧滑详情（2026-11-17）

任务列表不再上下分割，筛选区下方全高用于任务。目标描述、任务页、跨图跳转、物品列表移入列表左侧的非模态面板。宽度跟随任务侧栏，受地图宽度限制；高度与地图区一致，覆盖地图且不改变投影或列表宽度。

选中展开、取消选中收起。切换任务直接更新已展开内容，刷新保留有效选中；筛除任务自动清空并收起。关闭按钮和 Esc 都调用原取消选择逻辑，物品复制及手机端同步沿用原流程。手机现有布局未修改。

动画 180ms，16ms 计时，支持中途反向操作；关闭后计时器停止。描述和物品分别使用原生滚动，物品标题放在列表上方，缩放与调整窗口时保持可用高度。点击地图不关闭详情，不抢地图或任务搜索焦点。

专项验证选择、刷新、切换、760×480／1680×1050 布局、地图与列表边界保持、动画反向、Esc、关闭按钮、过滤后清除与计时器停止。TaskDescriptionBox 的滚轮和物品复制逻辑保留，完整回归继续执行原有滚动、跨图、主线、筛选和手机协议检查。

本地完整回归 5660 项通过，其中侧滑专项 20 项。构建无新增警告，保留原有 KeyCatalog／MarkerFloors 的 3 条可空性警告。
