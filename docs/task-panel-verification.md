# 任务面板验证（2026-11-16）

桌面完整回归通过 963 项，覆盖 25 张地图、88 个楼层视图；其中任务相关 48 项。浏览器通过 22 项交互检查。构建没有新增警告，保留 KeyCatalog 与 MarkerFloors 原有的 3 条可空性警告。

任务测试包括组合条件、最低等级边界、多目标类别、未知值、在线元数据解析、旧缓存补全、偏好持久化、有效选中保留、过滤后清空详情、跨图手动跳转、独立地图任务状态、滚轮、键盘、顶部可见行保持，以及 100/150/200% 字体与布局缩放下所有任务行的完整高度。

手机检查使用桌面导出的真实状态快照，验证两个客户端的条件同步、模拟异步动作回执、中文组合输入、防止轮询覆盖输入和光标、标签更新、独立地图状态、空结果恢复及 320/360px 窄屏。

## UI-SPEC §12 走查

| 项 | 结果 |
|---|---|
| 01 阴影无裁切 | 新区域不使用阴影；复用面板与分割线。 |
| 02 同心圆角 | 原生输入和现有按钮；手机沿用 4px 输入圆角。 |
| 03 微边框 | 任务行和筛选区使用 LineSubtle／--line-subtle。 |
| 04 光学重心 | 查看电脑及手机截图，标签、输入与按钮对齐。 |
| 05 无占位废话 | 电脑搜索与等级有可见字段名；手机输入有提示和无障碍名称。 |
| 06 主操作唯一 | 无新增实心强调按钮。 |
| 07 二选一中立 | 必需性筛选使用中立原生下拉。 |
| 08 状态有文案 | 各状态均有文字；未知状态使用中性色。 |
| 09 选型 | 单选条件使用原生下拉，等级使用输入框。 |
| 10 表单防手滑 | 不适用：条件即时生效，无编辑提交弹窗。 |
| 11 危险操作阻力 | 不适用：没有新增删除或清空进度操作；重置只改变筛选。 |
| 12 对齐 | 标题与标签左对齐，结果数量固定在任务标题。 |
| 13 横滚隔离 | 手机 320/360px 页面无横向溢出；长标签自动换行。 |
| 14 五态 | 初始数据由内置种子立即供应；有结果、无结果、离线/错误回退、字段缺失均有明确状态；原数据状态栏继续呈现刷新与错误。 |
| 15 复用组件 | 使用原生输入/下拉、现有按钮和抽屉；任务项因系统 ListBox 255px 高度上限改用 ScrollableControl 原生滚动，未新增自制滚轮逻辑。 |
| 16 等宽数字 | 手机条件摘要使用 tabular-nums；桌面结果计数在固定标题区域。 |
| 17 防孤字 | 长任务名与标签按正文宽度换行。 |
| 18 短词膨胀 | 手机按钮按内容留白，桌面按钮在固定侧栏内分配弹性列。 |
| 19 长文本 | 全部任务在 100/150/200% 文本/布局缩放下检查高度，不截断标签。 |
| 20 查询分层 | 搜索＋地区／状态／展开入口常驻，其余折叠；筛选只查询本地目录。 |
| 21 时间信息 | 元数据实际快照日期直接显示，不借用任务原始缓存日期。 |
| 22 视觉纪律 | 纯平列表、复用现有主题色，无新增渐变和装饰色。 |

补充元数据来自 2026-09-14 的公开 API 快照，覆盖种子数据中的 471/499 个任务；剩余 28 个任务的缺失字段保持未知。来源固定版本记录在 NOTICE 与种子的 taskMetadataSource 中。正常在线刷新会保存接口中的新字段及获取日期；上游当前的 403 不妨碍离线使用。
