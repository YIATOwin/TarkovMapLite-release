## 行为

- 默认及每次启动主线均关闭；即使上次开启，也不会通过偏好恢复。明确点击主线按钮或选择“主线任务”商人才会开启。
- 主线是独立商人分类，下设 10 个系列。522 个子目标逐项显示并保持顺序，23 条章节内分组标题作为上下文保留，不当作可定位任务。
- 日志任务 ID 与主线内部 ID 隔离；模拟日志完成事件也不会把主线行变为完成。状态、等级、阵营和 Kappa/灯塔商人条件在主线视图禁用。
- 主线只加载当前系列点位，关闭或换系列会移除原系列；商人区域不受影响。“仅进行中区域”不屏蔽手动开启的主线。
- 任务区域、圆点、连线、地图名称及越界箭头使用橙红色 #ff6d3d；手机绘制也需明确的开启标志。
- 可选目标单独标识；完整目标、分组说明、区域及跳转入口可查阅。没有坐标的目标不放置估算点。

## 数据边界

章节快照为 2026-08-11，坐标快照为 2026-08-26。来源共有 116 个子目标的 137 组坐标；现有地图可展示其中 97 个子目标、118 组坐标。剩余 19 组属于尚未收录底图的 Icebreaker（破冰船）；这些目标标记“底图未收录”，保留文字。其余无坐标目标标记“暂无坐标”。来源与许可说明在 NOTICE。

点位楼层是来源地图的附加图层索引：-1 为底图；例如工厂索引 2 对应 Basement，而非三层。导入时根据来源 floor 列表转换为层 ID，再对应本项目语义楼层。测试覆盖工厂地下、商场上层及 SVG/瓦片投影。
