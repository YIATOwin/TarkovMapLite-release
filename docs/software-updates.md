# 软件更新

## 玩家操作

0.4.12 首次加入更新入口，旧版需要先手动安装一次。启动约 4 秒后检查 GitHub 最新正式版，只提示，不自动下载。底部“软件更新”打开非模态面板；下载期间继续看地图，关闭面板不会取消下载。显式取消会清理未完成下载。校验完成后点击“重启并更新”才退出并替换程序。

支持跳过指定版本、稍后、手动检查和关闭启动检查。手动检查可重新显示跳过的版本。更新设置写入原 settings.json 的独立 updates 键，与截图目录、地图和任务偏好共存。搜索词与主线显示等运行期状态继续遵循各自规则。

连接方式为系统代理（默认）、直连或自定义 HTTP／HTTPS 代理；代理只用于更新。不能连接时保留地图与旧程序，并提供固定的官方发布页面入口。程序目录不可写时提示手动更新，不自动提权。

## 版本与下载

- 仓库固定为 YIATOwin/TarkovMapLite-release，仅接受数字正式版本 v主.次.修订（可带第四段），数值比较，只升不降。
- 首选 GitHub Releases latest API，拒绝草稿、预发布、不完整上传及非本仓库下载地址。API 请求超时或失败时，跟随官方 releases/latest 页面取得正式版本，再读取同版本 .sha256 和 exe HEAD 大小；缺失校验信息则提示手动更新。
- 元数据主请求 15 秒，页面回退 25 秒；HTTP 头和下载空闲超时 30 秒。最多 5 次 HTTPS 跳转，只允许 GitHub 及已知 GitHub 资源域名。
- exe 限制为 512 MiB 以下，按 64 KiB 流式写入并增量计算 SHA-256，检查精确字节数、Windows x64 PE、ProductName 与文件版本。进度约每 200 毫秒更新，不把整个安装包读入内存。
- 目前采用完整单文件更新，不做增量补丁。校验来自官方 GitHub 发布信息或同次发布的 SHA-256 文件。

## 替换与恢复

1. 下载写入 `%LOCALAPPDATA%\TarkovMapLite\Updates\<GUID>\payload.part`，校验成功后改名 payload.exe。
2. 玩家确认重启后，在后台复查 payload 和当前程序，测试目标目录写入权限，将当前 exe 复制为该会话的 updater.exe，生成包含目标路径、版本、哈希、父进程身份和随机 nonce 的 plan.json。
3. 以 `--apply-update <plan> <nonce>` 启动助手。助手校验身份并取得目标文件专属锁，发送 ready。20 秒内没收到 ready 时主窗口保持运行。助手最多等待原进程退出 2 分钟，期间允许取消。
4. 父进程退出后，在 exe 所在目录写入并校验 incoming 文件，再用 File.Replace 替换，旧程序保存在 `<exe>.backup.<GUID>`。
5. 新版以 `--updated-session <session> <nonce>` 启动，主窗口显示并处理消息后写 healthy。助手检查 PID、nonce 和版本；60 秒内没有有效确认或新版提前退出时，恢复旧程序并重新启动。启动确认之后发生的运行期问题不属于此次自动回退范围。
6. 只替换程序文件。结果写在会话 result.json 和 Updates/last-result.json。下一次成功更新会清理上次记录的本目标备份；失败新版保留为 `<exe>.failed.<GUID>` 供排查。超过 7 天的会话只清理约定文件，不递归删除未知内容。

首次准备失败可重试；重试清除旧取消／就绪／启动信号，避免误用上次助手状态。未来版本需要继续保留这两种启动参数与健康确认协议。仅代码回退，不改动或迁移玩家数据。

## 发布与验证

CI 检查标签与 csproj Version 一致，发布 TarkovMapLite.exe 与 TarkovMapLite.exe.sha256；正式标签形如 v0.4.12。无需自建更新服务器。

`tests/FloorRegression` 覆盖首次／损坏设置、正式版比较、来源和跳转限制、API 限流回退、流式下载／取消／损坏、替换冲突、回退与界面操作。完整回归继续检查地图、楼层、任务、主线与偏好。

`--update-integration <published-exe> <old-fixture> <new-fixture> <output>` 使用真实发布的助手与独立的 9.9.8／9.9.9 测试程序，在隔离目录验证父子握手、成功安装、启动失败回退、取消和重试、中文及特殊字符路径和设置保留。这些版本仅为测试夹具，不发布为应用版本。CI 在上传发布文件前运行此检查。

2026-11-16 验证：完整桌面回归 1101 项通过（软件更新 50 项），最终单文件进程集成 16 项通过。实网检查成功取得正式版本 v0.4.11，当前预览版 v0.4.12 不提示降级。构建保留 KeyCatalog／MarkerFloors 原有 3 条可空性警告，无新增警告。
