# 多点任务显示（2026-11-17）

总览只显示区域、点位及名称，不画关联线。分散点位各自标“任务名 · 1／2／3”，点位角标同步编号；同任务同楼层 22px 内近点聚合，放大展开。分组不按视口裁掉点位，因此平移不会让屏幕中的点因其它点出画而重新编号；缩放造成聚合或展开时会重新编号。

显式选中任务时，仅连接当前楼层的非候选点；取消选中恢复总览。关联线只表达同任务关系，不表示推荐路线或完成顺序。同一 findQuestItem 目标的多个位置是候选点，标“候选”，不参与连线；缺少目标 ID 的取物点同样采用保守规则，不猜测它们必须全部前往。

名称按四个方向避让、限制在视口内；点本身在视野外时不把名称挤到边缘。拥挤到无法放下完整标签时保留编号点。手机过长名称截短但保留序号和候选后缀。主线沿用橙红色及手动开启规则。

电脑 TaskMapLayout 和手机 taskMapGroups 使用相同 22px、同楼层分组规则。手机快照的每个 zone 新增 o（目标 ID）、t（类型），n 对全部任务提供名称；手机只绘制电脑投影后的坐标。

验证：本地完整回归 5640 项通过，其中多点绘制 11 项，实际检查总览没有连线、选中出现连线、取消后消失、另一任务不泄漏、候选／跨楼层不连线，以及远处第二个点的独立名称与编号。手机坐标与绘制专项 10 项，另运行筛选与主线专项。例图为 task-points-overview.png、task-points-selected.png、task-points-candidates.png。

UI-SPEC 走查：没有新增控件、颜色、圆角或字号；沿用地图文字、编号与状态色，名称左对齐，提供避让与长文本处理。图层、状态过滤、主线开关和选中规则继续由既有状态控制，不新增偏好设置。
